# Artemis

Artemis is Cutline Industries' operational AI. It connects tools, data, and workflows through one secure interface.

- **The Bow** — multi-model execution and generation console
- **Orion** — research, analysis, and vector ingestion
- **Chronicler** — persistent knowledge, hunts, and memory
- **Lunar Gate** — identity verification into Core Control

Voices: Astra (default), Orion, Nova, Sage.
