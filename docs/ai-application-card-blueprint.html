1. Overview

What this application is

The Cutline AI layer helps operators build Thermal (heat → clip → pay → retain), run agent tools, and print business blueprints. Cursor is the primary host. GitHub Copilot configs are optional mirrors.

Intended users

  • Founder / ops (Lamont) on Cursor desktop or cloud
  • Same person on phone for LAN print Ops bar
  • Optional: VS Code + Copilot teammates

4. Capabilities & limitations

Can do

  • Edit Thermal UI / API / docs
  • Open PRs from Cursor Cloud
  • MCP: phone-approval-lite
  • MCP: voice-print (local PC)
  • Run migrate / start / pipelines

Cannot do alone

  • Reach LAN printer from cloud
  • Spend Stripe / deploy prod without you
  • Bypass human PR review
  • Add buttons inside Cursor mobile UI

Human oversight

  • You approve merges
  • Secrets stay in .env (never commit)
  • Stripe webhook + keys are yours
  • Print jobs: you start PC server
