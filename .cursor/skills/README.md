# Cursor skills (OpenAI Developers)

Portable skills from [openai/openai-developers-for-cursor](https://github.com/openai/openai-developers-for-cursor) (Apache-2.0). Full pack installed in-repo.

| Skill | Use |
|-------|-----|
| [`openai-docs`](openai-docs/SKILL.md) | OpenAI product/API/model questions via Docs MCP |
| [`openai-platform-api-key`](openai-platform-api-key/SKILL.md) | Local `OPENAI_API_KEY` setup gate |
| [`openai-api-troubleshooting`](openai-api-troubleshooting/SKILL.md) | Classify API auth/quota/rate-limit failures |
| [`agents-sdk`](agents-sdk/SKILL.md) | Plan/build OpenAI Agents SDK apps |
| [`build-chatgpt-app`](build-chatgpt-app/SKILL.md) | Design/implement ChatGPT Apps SDK projects |
| [`chatgpt-app-submission`](chatgpt-app-submission/SKILL.md) | ChatGPT Apps submission guidance |

Docs MCP: `openaiDeveloperDocs` in `.cursor/mcp.json.example` → copy to `~/.cursor/mcp.json`. Desktop marketplace install (optional sync): [docs/OPENAI-DEVELOPERS-PLUGIN.md](../docs/OPENAI-DEVELOPERS-PLUGIN.md).
